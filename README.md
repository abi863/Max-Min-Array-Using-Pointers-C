# Maximum and Minimum in an Array Using Pointers in C

## Description

This program finds the maximum and minimum elements in an array using pointers and pointer arithmetic.

## Concepts Used

* Arrays
* Pointers
* Pointer arithmetic
* `for` loops
* Conditional statements

## How to Run

```bash
gcc max_min_pointers.c -o max_min_pointers.exe
./max_min_pointers.exe
```

## Language

C
